# 文档 Skill 测试入口

用户只需把本文件链接交给新 AI，并要求实际执行测试及输出报告。

本项目默认通过文件交接：先从 [AI 协作入口](../../../AI-START.md) 读取任务单和结果目录约定，再按以下批次执行。任务单只补充结果文件的写入范围，冻结测试输入与评分规则保持不变；已从任务单到达此处时，直接继续选择批次，不重复跳转。

1. 读取 [active-batch.json](active-batch.json)，确定默认测试批次。
2. 当前为 [v0.3.0 测试说明](batches/v0.3.0/RUN-TESTS.md)。按其中步骤获取材料、实际执行、保留输出、评审并交付报告。
3. 根目录旧 inputs、manifest 和手动指南是 v0.2.0 历史批次；除非明确回测，不混用旧输入与新评分规则。
4. 若本页与 active-batch.json 不同，以后者的显式路径为准，说明差异。

无法创建独立上下文时可做标明限制的演练，不得称为跨 AI 实测。无法访问文件时报告缺失，不编造结果。
