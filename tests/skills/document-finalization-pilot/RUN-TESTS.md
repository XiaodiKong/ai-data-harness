# 文档 Skill 测试入口

用户只需把本文件链接交给新 AI，并要求实际执行测试及输出报告。

本 Skill 的测试默认通过文件交接：先从 [Skill 测试协作入口](AI-START.md) 读取任务单和结果目录约定，再按以下批次执行。任务单规定本批次结果的写入范围和证据文件约定，冻结测试输入与评分规则保持不变；已从任务单到达此处时，直接继续选择批次，不重复跳转。

1. 读取 [active-batch.json](active-batch.json)，确定默认测试批次。
2. 当前为 [v0.3.3 测试说明](batches/v0.3.3/RUN-TESTS.md)。按其中步骤获取材料、实际执行、保留输出、评审并交付报告。
3. 根目录旧 inputs、manifest 和手动指南是 v0.2.0 历史批次；除非明确回测，不混用旧输入与新评分规则。
4. 若本页与 active-batch.json 不同，以后者的显式路径为准，说明差异。

无法创建独立上下文时可做标明限制的演练，不得称为跨 AI 实测。无法访问文件时报告缺失，不编造结果。

当前批次仅更新核心规则快照，沿用 v0.3.2 的业务输入、协议 4 和评分标准。它是 `text_only_core_skill` 测试，不包含可选 `references/` 文件，也不验证完整安装包或真实断网使用；冻结材料不等于测试已执行或通过。
